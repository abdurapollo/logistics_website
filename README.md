# TransMove Logistics — Corporate Website

A responsive corporate logistics website built strictly with **HTML5**, **CSS3**, and **Vanilla JavaScript**, closely reproducing the authoritative TransMove reference design.

## Project Structure

```text
├── index.html               # Semantic HTML5 markup for all 9 sections & modals
├── css/
│   └── style.css            # Complete design system, layout, animations & responsive styles
├── js/
│   └── script.js            # Vanilla JS navigation, counters, scroll reveals & modal forms
├── assets/
│   ├── images/              # High-resolution logistics photography assets
│   ├── icons/               # Custom SVG iconography
│   └── logo/                # TransMove vector brand mark
└── README.md
```

## Customization Guide

- **Brand Name & Contact Info**: Update the company name, phone number (`+91 98765 43210`), email (`hello@transmove.in`), and address directly in `index.html`.
- **Colors & Typography**: Modify the CSS custom properties in `:root` at the top of `css/style.css`.
- **Backend Form & Live Tracking Integration**: Connect your quote form endpoint and live carrier API inside `js/script.js` (sections 7 and 8).
